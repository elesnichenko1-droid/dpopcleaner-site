DPopCleaner 0.2.15 BETA — что делать

VS Code, Visual Studio и компилятор на вашем компьютере НЕ НУЖНЫ.

1. Распакуйте этот ZIP.
2. Загрузите СОДЕРЖИМОЕ архива в существующий GitHub-репозиторий:
   elesnichenko1-droid/dpopcleaner-site
   Файлы сайта можно заменить новыми. Папку .github тоже загрузите.
3. Сделайте Commit changes.
4. Откройте GitHub -> Actions.
5. Выберите "Build DPopCleaner 0.2.15 BETA".
6. Нажмите "Run workflow" -> "Run workflow".
7. GitHub на Windows сам соберёт программу и установщик.

После успешной сборки GitHub автоматически:
- создаст Release v0.2.15-beta;
- прикрепит DPopCleaner_Setup_0.2.15_BETA.exe;
- вычислит настоящий SHA-256;
- обновит update/beta.json;
- GitHub Pages автоматически обновит сайт;
- кнопка "Скачать" на сайте возьмёт URL/версию/размер/hash из beta.json.

ВАЖНО
Этот исходный проект — реконструированная база, а не оригинальные исходники старого EXE.
Первое обновление со старого 0.2.14 на 0.2.15 выполняется вручную.
Начиная с 0.2.15 приложение проверяет update/beta.json при запуске.

Пока установщик unsigned. SHA-256 проверяется, но автозапуск неподписанного обновления специально заблокирован.
Для снижения SmartScreen/Defender false positive следующим этапом нужен настоящий Authenticode code-signing сертификат.
