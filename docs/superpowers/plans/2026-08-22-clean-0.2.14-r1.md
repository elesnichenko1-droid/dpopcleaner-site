# DPopCleaner 0.2.14 R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, publish, and link a clean DPopCleaner 0.2.14 R1 installer that contains only the known standalone application executable.

**Architecture:** A policy test treats the installer definition, manifest, site, and GitHub Actions workflow as one release contract. GitHub Actions verifies the standalone EXE hash, optionally signs the staged EXE and installer, builds with Inno Setup, publishes one prerelease asset, writes manifest metadata, and deploys the static site.

**Tech Stack:** PowerShell 7, Inno Setup 6, GitHub Actions, GitHub Releases, static HTML/CSS/JavaScript.

**Spec:** `docs/superpowers/specs/2026-08-22-clean-0.2.14-r1-design.md`

## Global Constraints

- Never publish or copy the old installer with SHA-256 `0b0e7eeec6fe7a28eb046b083700bf7ce94ab4b0ee17bba9ee355203e8c8983e`.
- Accept only `downloads/DPopCleaner_0.2.14_BETA.exe` with SHA-256 `7d5e0a510189db31ef7ee1aca72dc182332a8020d994c81be40a519c5960515c` as the application payload.
- The installer contains one payload file and no WinDivert, winws, Zapret, `.bat`, `.cmd`, or `.ps1` payloads.
- The release tag is `v0.2.14-clean-r1`; the asset is `DPopCleaner_Setup_0.2.14_BETA_CLEAN_R1.exe`.
- No Defender disabling, exclusions, packers, obfuscation, self-signed certificates, or security-warning bypasses.
- The website enables downloads only for a valid available manifest with HTTPS URL, positive size, and 64-hex SHA-256.

- [ ] **Step 3: Implement strict manifest validation**

Create `release-manifest.js` as a small UMD-style module that exposes the predicate to both `module.exports` and `globalThis.DPopReleaseManifest`. Its core is:

```javascript
function isUsableManifest(m){
  return Boolean(
    m && m.version === '0.2.14' && Number(m.revision) === 1 &&
    m.available === true &&
    typeof m.download_url === 'string' &&
    /^https:\/\/github\.com\/elesnichenko1-droid\/dpopcleaner-site\/releases\/download\/v0\.2\.14-clean-r1\/DPopCleaner_Setup_0\.2\.14_BETA_CLEAN_R1\.exe$/.test(m.download_url) &&
    Number.isFinite(Number(m.size)) && Number(m.size) > 0 &&
    typeof m.sha256 === 'string' && /^[a-f0-9]{64}$/i.test(m.sha256)
  );
}
```

Load `release-manifest.js` before `script.js`. Use `DPopReleaseManifest.isUsableManifest` in `applyManifest`; use `0.2.14` as the fetch-error fallback. Keep all buttons disabled for an unusable manifest.
