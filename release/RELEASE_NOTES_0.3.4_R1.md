# DPopCleaner 0.3.4 BETA R1

0.3.4 возвращает UX-направление 0.2.14 и переносит его на исправленную современную сборочную базу.

## Главное

- левая вертикальная навигация в духе 0.2.14;
- 13 рабочих разделов: Обзор, Очистка, ОЗУ, DPopGuard, Автозагрузка, Диск, Приложения, Windows, Дубликаты, Инструменты, Zapret Center, Обновления и Настройки;
- DPI-aware layout с регрессионными проверками минимального окна и масштабирования;
- исправлено наложение текста и контента на странице Zapret;
- расширенный Zapret Center с выбором реальных bundled `general*.bat` стратегий;
- запуск выбранной/default стратегии, безопасная остановка только bundled `winws.exe`, Service Manager и открытие bundle;
- восстановлен отдельный раздел Автозагрузка на реальных HKCU/HKLM Run и Startup folders;
- восстановлен отдельный раздел Обновления на HTTPS manifest + SHA-256 + DPopUpdater;
- сохранены исправления 0.3.3, включая RecoveryControls `small -> smallFont`;
- Windows x64 build, CTest и UI smoke выполняются в GitHub Actions перед публикацией.

## Zapret

В установщик входит проверенный Zapret 1.10.1 bundle. DPopCleaner не запускает службу или стратегию без явного действия пользователя и не должен завершать сторонние VPN-процессы.

## Статус

BETA. Сборка предназначена для Windows 10/11 x64.
