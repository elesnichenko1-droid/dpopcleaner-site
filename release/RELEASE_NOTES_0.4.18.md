# DPopCleaner 0.4.18 rev.2

DPopCleaner 0.4.18 — стабильное обновление основного приложения после 0.4.17. Rev.2 сохраняет весь функционал rev.1 и исправляет визуальную идентичность Windows-приложения и сайта.

## Исправления rev.2

- **Возвращена иконка DPopCleaner.** Каноническая иконка снова встроена в `DPopCleaner.exe` и `DPopUpdater.exe`, используется окном приложения, установщиком и основными ярлыками Windows.
- **Добавлен icon-smoke.** Production pipeline извлекает icon resource из собранных EXE и установщика, чтобы иконка больше не могла незаметно исчезнуть.
- **Исправлены скриншоты сайта.** Старые изображения интерфейса 0.4.17 больше не публикуются. Windows CI запускает текущий `DPopCleaner.exe` и снимает реальные скриншоты страниц «Обзор», «Zapret» и «Настройки» через `PrintWindow`.

## Главное в 0.4.18

- **Мгновенное закрытие окна.** Сетевая проверка обновлений больше не удерживает DPopCleaner при выходе; отдельный 10-секундный slow-update smoke блокирует регрессию.
- **Управляемое автообновление.** В настройках можно отключить автоматическую проверку, при этом кнопка «Проверить обновления сейчас» остаётся доступной.
- **DPopUpdater.exe.** Обновление принимается только после проверки точного размера и SHA-256 установщика; updater повторно проверяет пакет перед передачей установщику.
- **Анализатор диска и Центр восстановления** продолжают поставляться как проверенные companion-модули.

## Встроенный Zapret

DPopCleaner 0.4.18 включает **Flowseal Zapret 1.10.2** прямо в установщик по пути `ThirdParty\Zapret`.

- upstream ZIP `zapret-discord-youtube-1.10.2.zip` проверяется по точному размеру и SHA-256 **до распаковки**;
- bundled runtime содержит `winws.exe`, WinDivert, стратегии, списки и `service.bat`;
- в основном окне доступны статус, выбор стратегии, запуск/остановка и управление службой;
- внешний `winws.exe` не завершается по имени: ownership определяется по полному пути bundled runtime;
- Discord screen-sharing fix остаётся отдельным инструментом для явного применения/отката;
- при переустановке пользовательский `list-general-user.txt` и другие `lists\*-user.txt` сохраняются через `%LOCALAPPDATA%\DPopCleaner\ZapretBackup` и восстанавливаются после замены program-owned tree.

WinDivert может вызывать предупреждения антивирусов/PUA. DPopCleaner не добавляет исключения автоматически и не скачивает произвольные Zapret-бинарники во время работы приложения.

## Проверка релиза

Production pipeline заново выполняет native CTest, UI contract, slow-close smoke, icon-smoke, реальные скриншоты текущего UI, companion tests, pinned Zapret verification, exact staging, Inno Setup build и установленную/повторную установку. Только после этого создаётся stable manifest с фактическим размером и SHA-256 опубликованного `DPopCleaner_Setup_0.4.18.exe`.

Обновление с 0.4.17 и с 0.4.18 rev.1 не является обязательным, но рекомендуется для встроенного Zapret, нового lifecycle, восстановленной иконки и корректных материалов сайта.
