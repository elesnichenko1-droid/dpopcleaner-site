# DPopCleaner 0.4.17 rev.11

DPopCleaner 0.4.17 rev.11 исправляет две регрессии rev.10 без нового интерфейса. **Прежний интерфейс сохранён**: мы редактируем существующие контролы там, где это возможно, а оригинальное ядро 0.2.14 остаётся byte-identical как `{app}\DPopCleaner.Core.exe` с Git blob `efd0eff1f4962319282363fa85595c25e0cebe11`.

## Revision 11

- Исправлены визуальные «следы» и слияние элементов в **Настройках** после прокрутки. Дочерние элементы существующего scroll-host теперь перемещаются одной атомарной операцией `BeginDeferWindowPos/DeferWindowPos/EndDeferWindowPos`, после фактического изменения позиции выполняется одна полная **перерисовка** host-а и детей через `RedrawWindow`.
- Если scroll уже находится на границе и положение не изменилось, лишней перерисовки нет.
- Сохраняется исправление rev.10 против «улетания» Настроек: координаты самого Settings-host фиксируются по исходной странице и не вычисляются заново по прокрученным proxy-чекбоксам.
- Исправление версии Zapret переделано принципиально: rev.11 **не создаёт новый version proxy** и не накладывает отдельный Static поверх старого интерфейса.
- Используется **родной существующий Static frozen-core**, который раньше показывал `Zapret 1.9.9d • ...`. Bridge ставит subclass на этот же контрол и перехватывает `WM_SETTEXT`, заменяя только префикс версии на реально установленную версию из `{app}\Zapret\.service\version.txt`.
- Нативная часть строки `• сервис ... • winws ...` остаётся той, которую формирует старое ядро. Для текущего комплекта строка начинается с **Zapret 1.10.2**, а `1.9.9d` больше не должна появляться даже при последующих обновлениях статуса ядром.
- Удалён rev.10 proxy с ID `1726`, который мог мигать из-за повторных обновлений каждые 100 мс.
- Тёмный **owner-draw** формат шести уже существующих bridge-кнопок сохранён. Кнопки перерисовываются только при первом подключении стиля или реальном изменении текста, а не на каждом тике launcher-а.
- Подписи `Игровой фильтр 1.10.2` и `Менеджер 1.10.2` по-прежнему получают номер из установленного `version.txt`.
- Полный **Flowseal Zapret 1.10.2** и все прежние **22 стратегии** сохранены.

## Сохранено из предыдущих revision

- Штатные сломанные frozen-кнопки **«Проверить версию»** и **«Скачать и установить»** остаются заменены существующим bridge-updater; пользователь больше не должен попадать в старое окно **«Модуль обновления Zapret не найден»**.
- `{app}\DPopUpdate.exe` остаётся как legacy-совместимость.
- Сохраняются кнопки **«Починка трансляции»**, **«Починка подключения»**, **«Игровой фильтр 1.10.2»** и **«Менеджер 1.10.2»** в существующей вкладке Zapret.
- Во вкладке **ОЗУ** используется существующий ComboBox с диапазоном **5–95%**.
- В Настройках остаются существующие опции, **автообновление приложения**, ручная проверка обновлений и лицензия; правая колонка «Исключения очистки» не переделывается.
- Исправление **демонстрации экрана Zapret** через `ZapretScreenFix.exe`, Disk Analyzer и Restore Center сохраняются.

## Проверка rev.11

Windows CI собирает реальный Inno Setup installer и устанавливает его на чистом runner. Отдельный `dpop0417_rev11_existing_ui_smoke.ps1` агрессивно прокручивает Настройки, повторно открывает вкладку, затем открывает Zapret и требует: отсутствие proxy ID `1726`, один и тот же родной Static с `Zapret 1.10.2` в течение нескольких секунд, отсутствие видимого `Zapret 1.9.9d`, а также тёмный owner-draw формат существующих кнопок. Сохраняется rev.9 click-smoke для рабочей кнопки «Скачать и установить».

## Публикация

Stable manifest для **revision 11** публикуется только после зелёной installed-проверки. Production publisher создаёт GitHub Release `v0.4.17-rev11`, публикует Pages и затем повторно скачивает живой installer для проверки SHA-256 и размера.

## Установка

Запустите `DPopCleaner_Setup_0.4.17.exe` поверх rev.10. После установки запускайте обычный `DPopCleaner.exe`.
