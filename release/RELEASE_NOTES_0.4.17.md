# DPopCleaner 0.4.17 rev.7

DPopCleaner 0.4.17 rev.7 — функциональный hotfix поверх прежнего интерфейса. **Прежний интерфейс сохранён**: дизайн приложения не менялся, C++-интерфейс не внедрялся. Работа выполнена через существующий launcher/UI-bridge, а оригинальное ядро 0.2.14 сохранено byte-identical как `{app}\DPopCleaner.Core.exe` с Git blob `efd0eff1f4962319282363fa85595c25e0cebe11`.

## Revision 7

- Исправлена причина закрытия приложения при временном скрытии, сворачивании или восстановлении окна: launcher завершает работу только после фактического завершения процесса ядра, а временная невидимость окна больше не считается сигналом выхода.
- Во вкладке **ОЗУ** сохранён существующий ComboBox, диапазон порога очистки расширен до **5–95%** с шагом 5%.
- Существующая вкладка **Zapret** сохранена и дополнена действиями **«Починка трансляции»**, **«Починка подключения»**, **«Игровой фильтр 1.10.2»** и **«Менеджер 1.10.2»**.
- Полный pinned **Flowseal Zapret 1.10.2** и прежние 22 стратегии сохранены.
- В **Настройках** прокручивается именно существующая левая область с прежними чекбоксами; правая колонка **«Исключения очистки»** не изменена.
- В прокручиваемой левой области сохранены прежние 6 чекбоксов, добавлены **«Включить автообновление приложения»**, **«Проверить обновления»**, а ниже остаётся лицензия.
- Устаревшая надпись `v0.2.11 BETA` скрывается UI-bridge.
- `DPopCleaner.exe` остаётся совместимым launcher/UI-bridge, `SimpleUpdate.exe` — его совместимым вторым именем, а неизменное ядро запускается как `DPopCleaner.Core.exe`.

## Проверка rev.7

Windows CI проверяет настоящий установленный пакет после Inno Setup установки. Installed smoke запускает `{app}\DPopCleaner.exe` и требует успешную проверку скрытия/восстановления окна, диапазона ОЗУ 5–95%, новых кнопок Zapret, прокрутки Настроек, автообновления приложения, отсутствия видимого `v0.2.11 BETA`, полного Flowseal Zapret 1.10.2, companion-модулей и последующего uninstall.

Ключевые функциональные результаты rev.7:

- `REV7_INSTALLED_FUNCTIONAL_UI_SMOKE_OK`
- `Installed rev.7 hide/restore + RAM + Zapret + Settings functional smoke: PASS`

## Сохранено из предыдущих revision

- Полный `Zapret\` runtime: `Zapret\service.bat`, `Zapret\general.bat`, остальные стратегии `Zapret\general*.bat`, `Zapret\bin\winws.exe`, WinDivert, `.service`, `lists` и `utils`.
- `ZapretScreenFix.exe` и команда `zapret-screen-fix` сохраняют исправление демонстрации экрана при использовании Zapret.
- Анализатор диска и Центр восстановления остаются отдельными companion-модулями.
- `SimpleUpdate` проверяет stable manifest по HTTPS, сравнивает `version_code + revision`, а загруженный установщик принимает только после совпадения размера и SHA-256.
- Исторический путь `{app}\DPopCleaner.exe` остаётся launcher-входом, поэтому старые ярлыки не обходят UI-bridge.

## Публикация

Stable manifest для revision 7 публикуется только после сборки и проверки реального `DPopCleaner_Setup_0.4.17.exe`. Production publisher создаёт GitHub Release `v0.4.17-rev7`, публикует Pages, затем повторно скачивает живой установщик и сверяет его размер и SHA-256 с проверенным release candidate.

## Установка

Запустите `DPopCleaner_Setup_0.4.17.exe`. После установки запускайте обычный `DPopCleaner.exe`: это совместимый вход в UI-bridge, который запускает сохранённое ядро `DPopCleaner.Core.exe`.

Перед системными изменениями рекомендуется иметь актуальную точку восстановления Windows или резервную копию важных данных.
