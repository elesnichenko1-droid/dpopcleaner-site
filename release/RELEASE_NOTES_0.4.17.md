# DPopCleaner 0.4.17 rev.8

DPopCleaner 0.4.17 rev.8 — post-release hotfix для существующего интерфейса. **Прежний интерфейс сохранён**: дизайн приложения не менялся, C++-интерфейс не внедрялся. Работа выполнена через существующий launcher/UI-bridge, а оригинальное ядро 0.2.14 сохранено byte-identical как `{app}\DPopCleaner.Core.exe` с Git blob `efd0eff1f4962319282363fa85595c25e0cebe11`.

## Revision 8

- Исправлена ошибка старой вкладки **Zapret**: при нажатии штатного обновления frozen-core ожидал `{app}\DPopUpdate.exe` и показывал **«Модуль обновления не найден»**, потому что rev.7 не устанавливала этот совместимый модуль.
- Установщик снова создаёт ожидаемый `{app}\DPopUpdate.exe`, используя тот же проверенный `SimpleUpdate.exe`. При запуске под историческим именем бинарник переходит в отдельный режим обновления Zapret **до** захвата launcher-mutex и не запускает вторую копию DPopCleaner.
- Режим `DPopUpdate.exe` сверяет локальный `Zapret\.service\version.txt` с официальной версией **Flowseal/zapret-discord-youtube**. Если версия актуальна, пользователь получает понятное подтверждение. Если upstream новее, предлагается открыть официальную страницу последнего релиза Flowseal; при сетевой ошибке можно открыть официальный `service.bat` manager.
- На момент выпуска rev.8 официальный latest Flowseal остаётся **Zapret 1.10.2**, поэтому пакет по-прежнему содержит pinned **Flowseal Zapret 1.10.2** и все прежние **22 стратегии**.
- Четыре дополнительные действия Zapret теперь собраны в **одну компактную строку** рядом с заголовком **«Дополнительно»**. Блок не перекрывает штатные кнопки `Применить`, `IPSet`, `Обновить IPSet`, `Обновить hosts`, `Диагностика` и `Тесты`.
- Сохранены все действия rev.7: **«Починка трансляции»**, **«Починка подключения»**, **«Игровой фильтр 1.10.2»**, **«Менеджер 1.10.2»**.

## Сохранено из revision 7

- Исправлено закрытие приложения при временном скрытии, сворачивании или восстановлении окна: launcher завершает работу только после фактического завершения процесса ядра.
- Во вкладке **ОЗУ** сохранён существующий ComboBox, диапазон порога очистки — **5–95%** с шагом 5%.
- В **Настройках** прокручивается существующая левая область с прежними 6 чекбоксами, **«Включить автообновление приложения»**, **«Проверить обновления»** и лицензией; правая колонка **«Исключения очистки»** не изменена.
- Устаревшая надпись `v0.2.11 BETA` скрывается UI-bridge.
- `DPopCleaner.exe` остаётся launcher/UI-bridge, `SimpleUpdate.exe` — его совместимым вторым именем, неизменное ядро запускается как `DPopCleaner.Core.exe`.
- `ZapretScreenFix.exe` и исправление демонстрации экрана сохраняются.

## Проверка rev.8

Windows CI собирает настоящий Inno Setup installer, устанавливает его и проверяет установленное приложение. В smoke обязательно проверяются:

- `DPopUpdate.exe` присутствует в корне установки и byte-for-byte совпадает с проверенным `SimpleUpdate.exe`;
- результат `Legacy Zapret updater compatibility module: PASS`;
- четыре дополнительные кнопки Zapret присутствуют и не перекрывают друг друга;
- компактный Zapret toolbar не перекрывает штатные элементы старой вкладки;
- `REV7_INSTALLED_FUNCTIONAL_UI_SMOKE_OK` как накопительный regression-smoke для hide/restore, ОЗУ 5–95%, Zapret и прокрутки Настроек;
- полный Flowseal Zapret 1.10.2 и 22 стратегии;
- byte-identical `DPopCleaner.Core.exe`;
- Disk Analyzer, Restore Center, Zapret Screen Fix и silent uninstall.

## Обновление Zapret

Rev.8 устраняет именно ошибку отсутствующего legacy-модуля. `DPopUpdate.exe` проверяет официальную версию Flowseal и направляет пользователя на официальный релиз/manager при необходимости. Он **не выполняет скрытую автоматическую замену сторонних файлов Zapret без подтверждения пользователя**.

## Публикация

Stable manifest для **revision 8** публикуется только после сборки и проверки реального `DPopCleaner_Setup_0.4.17.exe`. Production publisher создаёт GitHub Release `v0.4.17-rev8`, публикует Pages, затем повторно скачивает живой installer и сверяет его размер и SHA-256 с проверенным release candidate.

## Установка

Запустите `DPopCleaner_Setup_0.4.17.exe`. После установки запускайте обычный `DPopCleaner.exe`. Пользователь rev.7 увидит rev.8 как новое обновление по stable manifest.

Перед системными изменениями рекомендуется иметь актуальную точку восстановления Windows или резервную копию важных данных.
