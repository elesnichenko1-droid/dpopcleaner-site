DPopCleaner 0.3.1 — безопасность релиза

Нельзя гарантировать, что новый неподписанный EXE никогда не получит ложное срабатывание SmartScreen/антивируса.
В 0.3.1 специально НЕ используются:
- UPX и кастомные packer-ы;
- обфускация ради обхода защит;
- PowerShell/cmd для скачивания и запуска обновлений;
- отключение Microsoft Defender;
- исключения Defender;
- попытки скрыть системные действия.

Updater использует HTTPS + SHA-256. Для подписанного релиза дополнительно проверяется Authenticode.
Лучший следующий шаг для снижения предупреждений: приобрести/подключить настоящий Windows Code Signing сертификат и подписывать DPopCleaner.exe, DPopUpdater.exe и installer одним издателем.
