DPopCleaner 0.2.15 — исправление сайта
=======================================

ПОЧЕМУ БЫЛ 404:
Старая страница 0.2.14 ссылалась на GitHub Release/файл, которого не существовало.

ЧТО ДЕЛАЕТ ЭТОТ ПАКЕТ:
1. На сайте везде 0.2.15.
2. Пока установщик не создан, кнопка показывает «Сборка готовится» и НЕ ведёт на 404.
3. После загрузки всего пакета GitHub Actions автоматически пытается собрать DPopCleaner 0.2.15.
4. После успешной сборки создаётся Release v0.2.15-beta и beta.json получает настоящий URL, размер и SHA-256.
5. Сайт повторно публикуется, и кнопка скачивания становится рабочей автоматически.
6. static.yml публикует ТОЛЬКО веб-файлы — src/ не попадает на GitHub Pages.

КАК ЗАГРУЗИТЬ:
- Распакуйте ZIP.
- В репозитории dpopcleaner-site: Code -> Add file -> Upload files.
- Перетащите ВСЁ содержимое распакованной папки, включая .github.
- Commit changes.
- Откройте Actions.
- Должны появиться два workflow:
  * Deploy static content to Pages
  * Build DPopCleaner 0.2.15 BETA
- Дождитесь зелёной галочки у Build DPopCleaner 0.2.15 BETA.
- После этого Ctrl+F5 на сайте.

ЕСЛИ BUILD КРАСНЫЙ:
Откройте красный workflow и пришлите скриншот/текст первой ошибки.
