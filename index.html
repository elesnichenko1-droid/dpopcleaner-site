Надёжность

Проверенная сборка и понятная загрузка

Сайт показывает данные стабильного релиза, размер файла и SHA‑256. В комплекте сохраняются Flowseal Zapret 1.10.2 со всеми 22 стратегиями, основные модули DPopCleaner и проверяемое ядро DPopCleaner.Core.exe.

Технические детали rev.16

В rev.16 bridge переживает штатный перезапуск frozen core при смене языка: launcher подхватывает новый PID из того же пути, повторно создаёт enhanced Settings и восстанавливает цифровой RAM tray-host вместо возврата прежнего интерфейса и исчезновения цифр из трея.

В rev.14 исправлена синхронизация Settings с native Language ComboBox: bridge-owned элементы следуют выбранному языку. В rev.13 исправлен запуск после установки: launcher встроен как asInvoker и сам запрашивает UAC через runas, поэтому сценарий CreateProcessAsUser / code 740 больше не должен ломать первый запуск. Legacy-иконка frozen core и ghost-записи Explorer подавляются.

Для rev.12 исправлена родная версия Zapret через Zapret\utils\dpop_version.txt: прежний fallback 1.9.9d больше не должен отображаться. Bridge не переписывает родную версию через HWND. Исправления прокрутки и перерисовки Настроек сохранены.

Также сохранены «Починка трансляции», «Починка подключения», «Игровой фильтр 1.10.2», «Менеджер 1.10.2» и исправление демонстрации экрана Zapret.
