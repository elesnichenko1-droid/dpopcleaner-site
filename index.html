FAQ

Перед установкой

Коротко о текущей BETA.

Что главное в 0.3.5 R1?

Вернулся компактный UX в духе 0.2.14, «Диск» стал TreeSize-подобным иерархическим анализатором, а Settings получили пять реальных секций с сохранением и runtime-применением.

Для какой Windows предназначена сборка?

Windows 10/11 x64.

Что означает «Занято» в анализаторе диска?

Это физически выделенный размер, когда Windows может его безопасно определить. Если значение недоступно, DPopCleaner показывает «—», а не подменяет его логическим размером.

Где хранятся настройки?

В локальном settings.json DPopCleaner. Запись выполняется атомарно; повреждённый файл не должен ломать запуск приложения.

Как проверить установщик?

Сравните SHA-256 файла со значением на странице. Production pipeline после публикации скачивает тот же installer по публичной ссылке и повторно проверяет хеш.
