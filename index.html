FAQ

Перед установкой

Короткие ответы на вопросы, которые особенно важны для BETA-версии.

Для какой Windows предназначен DPopCleaner?

Текущий установщик собран под 64-битную Windows. Для сайта мы позиционируем релиз для Windows 10 и Windows 11 x64.

Почему некоторые действия требуют администратора?

Управление системными списками памяти, компонентами Windows и частью обслуживающих операций требует повышенных прав. Приложение запрашивает их только для таких сценариев.

DPopGuard 2 заменяет антивирус?

Нет. В 0.2.14 BETA это дополнительная эвристическая проверка автозапуска. Она ничего не удаляет автоматически и не заменяет Microsoft Defender или другой антивирус.

Как проверить скачанный установщик?

Вычислите SHA-256 файла и сравните его со значением на этой странице. Для текущего BETA-релиза ожидаемый хеш загружается из update/beta.json и отображается выше.
