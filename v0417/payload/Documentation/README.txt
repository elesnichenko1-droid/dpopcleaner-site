DPopCleaner 0.4.17 — Documentation

Эта папка хранит состояние, которое создают новые модули DPopCleaner для истории и безопасного отката.

History  — записи о выполненных поддерживаемых действиях.
Backups  — данные, необходимые для восстановления предыдущего состояния.
Logs     — диагностические журналы.

Кнопка восстановления должна появляться только для действий, для которых DPopCleaner сохранил достаточно данных для безопасного отката. Для необратимых действий отображается «Откат недоступен».

Папка Documentation предназначена для сохранения при обычном обновлении и удалении программы.
