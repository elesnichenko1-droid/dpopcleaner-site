DPopCleaner 0.2.15 BETA — сборка без Visual Studio/VS Code

Этот пакет рассчитан на загрузку в GitHub. GitHub Actions сам:
1) собирает Windows x64 DPopCleaner.exe и DPopUpdater.exe;
2) создаёт DPopCleaner_Setup_0.2.15_BETA.exe;
3) считает SHA-256;
4) создаёт/обновляет Release v0.2.15-beta;
5) обновляет update/beta.json для сайта.

После загрузки файлов в репозиторий:
Actions -> Build DPopCleaner 0.2.15 BETA -> Run workflow.

ВАЖНО: установщик пока НЕ подписан Authenticode. Не отключайте Defender ради него.
Чтобы автоматическая установка была безопасной и вызывала меньше предупреждений SmartScreen,
позже нужен настоящий code-signing сертификат. До этого приложение скачивает обновление,
проверяет SHA-256, но не запускает unsigned-пакет автоматически.

Первый переход со старого DPopCleaner 0.2.14 на 0.2.15 будет ручным,
поскольку исходный 0.2.14 не содержит нового UpdateClient. Начиная с 0.2.15,
проверка сайта встроена в приложение.
