DPopCleaner Website — safe website-only package

This package intentionally contains NO .exe, .dll, .bat, .cmd, .ps1 or other executable files.

Contents:
- index.html — main page
- styles.css — styles
- script.js — website interactions
- version.json — release metadata (installer is currently null)
- assets/ — images
- .github/workflows/pages.yml — GitHub Pages deployment workflow
- .nojekyll — GitHub Pages setting

The download buttons are intentionally disabled until a separate signed release is published.
