ВОЗВРАТ ОРИГИНАЛЬНОГО DPopCleaner 0.2.14

1. Загрузите содержимое этого ZIP в корень dpopcleaner-site с заменой файлов.
2. Отдельно загрузите оригинальный установщик:
   DPopCleaner_Setup_0.2.14_BETA.exe
   в папку:
   downloads/
3. Путь в репозитории должен быть:
   downloads/DPopCleaner_Setup_0.2.14_BETA.exe
4. Commit changes.
5. Actions -> Deploy static content to Pages -> Run workflow -> main.
6. После зелёной галочки обновите сайт Ctrl+F5.
